Changes made during the session, all recorded here and in the scripts:

1. The first palace:cpu image could not start Palace. Its runtime stage had
   no which(1), which the palace launcher script calls, and no
   libopenblas.so.0, which Rocky 9 now ships in openblas-serial rather than
   openblas. Both were added to the Dockerfile and the runtime stage was
   rebuilt; the builder stage (the Palace compile) came from the build cache
   unchanged. build_provenance.txt has both image ids and Dockerfile hashes.
   palace/Dockerfile.used is the exact recipe of the image that ran
   (sha256 00ddd295...). Issue #927 made the same fixes to
   reference/palace/docker/Dockerfile independently on the same day, and
   this branch takes main's version: same Palace pin (PALACE_REF, defaulting
   there to fba6a5b), the same runtime packages, plus a build-info file
   written by the builder stage. So the committed recipe is equivalent to,
   not byte-identical with, the one that ran.

2. Chain D (Palace with AMS) was added after chain B had started, when
   Palace's source showed that "Default" resolves to SuperLU for a driven
   problem in a build with SuperLU (palace/utils/iodata.cpp at fba6a5b).
   Chain B ran box_palace_cpu.sh before its PALACE_LINEAR_TYPE option
   existed; that version always wrote Type "Default", which is what the
   current version writes when the option is unset (the configs in palace/
   are byte-identical in form to the #520 ones; the *_config.json files are
   the record).

3. Chains C and E were written during the session once the priority cells
   were done and box time was left. Chain E's size (n = 50) is outside the
   five sizes the run was scoped for.

4. Direct was not run at n = 40 or 50: one LU took 78 GB at n = 36 and the
   box has 128 GB. Direct was not run single-threaded at n = 36.

The geode checkout on the box was a clean clone of 64d44269 (git=... dirty=0
in every .meta). ams_cpu_sweep.sh, box_palace_cpu.sh and palace_driven_cfg.py
ran from this branch's copies; the Dockerfile from palace/Dockerfile.used.
